### 📌 작업 개요

저장소 내부에 생성되는 `.gradle-user-home/`을 Git 추적 대상에서 제외했다.
ignore 규칙이 없어 로컬 빌드만 돌려도 이 폴더 전체가 미추적 파일로 잡히던 상태를 정리한 것이다.

### 🎯 구현 목표

- `.gradle-user-home/`이 `git status`에 나타나지 않게 한다
- 기존 Gradle 산출물·IDE 제외 규칙과 같은 자리에 둔다

### ✅ 구현 내용

#### gitignore 규칙 추가

- **파일**: `.gitignore`
- **변경 내용**: `build/` · `.gradle/` 다음 줄에 `.gradle-user-home/` 추가 (1줄)
- **이유**: 이 폴더에는 Gradle 배포본·의존성 캐시·daemon 로그·lock 파일 같은 로컬 실행 산출물만 들어간다.
  Gradle이 언제든 다시 만들 수 있고 개발 환경마다 내용이 달라 소스로 관리할 이유가 없다

규칙을 `.gradle/` 바로 아래 넣어 Gradle 관련 제외가 한 자리에 모이게 했다.

### 🧭 결정 기록 (ADR)

해당 없음 — 기존 ignore 규칙 형식을 그대로 따랐다.

### 🧪 테스트 및 검증

로컬 빌드 후 `git status`에서 `.gradle-user-home/`이 사라지는 것으로 확인한다.

### 📌 참고사항

- 이미 추적 중인 파일에는 ignore가 적용되지 않는다. 이 폴더가 커밋된 적은 없어 추가 조치는 필요 없었다
- 프로젝트 소스·Gradle Wrapper 설정·기존 캐시 파일은 변경하거나 삭제하지 않았다
