### 📌 작업 개요

`HostAdminController`의 매핑을 `/api/admin/hosts`에서 `/admin/hosts`로 바꿨다.
명세와 프론트는 접두사를 쓰지 않는데 백엔드만 `/api`를 붙이고 있어, 프론트가 실제 백엔드를 호출하면 404가 나던 상태였다.

### 🔍 문제 분석

접두사가 근거마다 갈려 있었다.

| 근거 | 경로 |
| --- | --- |
| 노션 `FESTA API (MVP)`의 URL 컬럼 | `/admin/festivals`, `/admin/hosts` — 접두사 없음 |
| DOC-0007 「경로 접두사는 붙이지 않는다」 | 검토 결과 붙이지 않기로 했다 |
| 머지된 `HostAdminController` (PR #23) | `@RequestMapping("/api/admin/hosts")` — `/api` 있음 |

`/api`를 붙이지 않기로 한 판단에 **결정 노트가 없었다.** 문서 본문에만 남아 있어 인용할 id가 없었고,
그래서 구현이 반대 방향으로 갔다.

프론트는 확인 결과 접두사를 쓰지 않는다. `API_BASE`가 호스트까지만 담고 경로가 접두사 없이 붙으며,
목 핸들러 4종(festivals · artists · hosts · search)도 모두 같다.
즉 **명세 URL 컬럼과 프론트가 같은 편이고 백엔드만 달랐다.**

**지금 고쳐야 하는 이유가 하나 더 있었다.** 관리자 인증을 붙이면서 `SecurityConfig`의 매처를 `/admin/**`로
걸 예정인데, 컨트롤러가 `/api/admin/hosts`에 남아 있으면 **매처에 걸리지 않아 인증 없이 뚫린 채로 남는다.**
보호가 아무것도 하지 않으면서 켜져 있는 것처럼 보이는 상태가 된다.

### ✅ 구현 내용

#### 컨트롤러 매핑 변경

- **파일**: `src/main/java/com/greedy/festa/host/controller/HostAdminController.java`
- **변경 내용**: `@RequestMapping("/api/admin/hosts")` → `@RequestMapping("/admin/hosts")` (1줄)
- **이유**: 명세·프론트와 백엔드를 맞추고, 이후 들어올 `/admin/**` 시큐리티 매처의 사정권에 들어가게 한다

### 🧭 결정 기록 (ADR)

#### 프론트와 합의하지 않고 백엔드를 정정

- **문제**: 외부 동작이 바뀌는 변경(관리자 API URL)을 합의 없이 진행해도 되는지
- **선택**: 합의 없이 백엔드를 고쳤다. `festa-frontend`의 `origin/develop`을 직접 확인한 결과
  프론트는 이미 접두사를 쓰지 않았고, 명세도 같은 편이었다
- **대안**: 프론트와 조율 후 진행 — 바꿀 쪽이 백엔드 하나뿐인데 조율 비용만 든다
- **트레이드오프**: 외부 동작이 바뀌는 변경이므로 배포 순서에 주의가 필요하다.
  다만 현재 프론트가 실제 백엔드를 호출하면 404가 나던 상태였으므로, 이 변경으로 깨질 호출은 없다

#### 결정 노트로 승격

- **문제**: 같은 실수가 재발할 수 있다. 판단의 근거가 문서 본문에만 있으면 인용할 id가 없다
- **선택**: 접두사를 붙이지 않는다는 판단을 결정 노트 **DEC-0084**로 승격했다
- ⭐ **볼트 승격 권장** — 승격 완료. 이후 컨트롤러는 이 결정을 인용해 접두사 없이 매핑한다

### 🧪 테스트 및 검증

컨트롤러 매핑 한 줄 변경이라 단위 테스트 대상이 아니다.
검증은 변경 후 `/admin/hosts`로 요청이 도달하는지, 그리고 이후 `/admin/**` 시큐리티 매처에
실제로 걸리는지로 확인한다.

### 📌 참고사항

- 이 작업의 범위는 컨트롤러 한 줄이다. 이슈가 함께 적은 나머지는 코드 밖 작업이다 —
  노션 명세 본문에 남은 `/api` 표기 정리(축제 요약 페이지, 주최 상세 페이지, 에러 코드 표의
  `INVALID_PATH_VARIABLE` 예시)와 결정 노트 승격
- **앞으로 추가되는 관리자 컨트롤러도 접두사 없이 매핑한다.** 이 정정의 이유가 시큐리티 매처와 얽혀 있으므로,
  하나라도 `/api`로 돌아가면 그 엔드포인트만 인증에서 빠진다
